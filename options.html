时光库 · 设置

把网页正文和图片保存到你的 GitHub 仓库

GitHub 访问

需要一个有 Contents: Read and write 权限的 Personal Access Token。 推荐使用 Fine-grained token，并只勾选 shiguang 仓库。 创建 Token · 使用经典 Token（勾选 repo）

保存规则

  • 目录结构：clips/2026-10-31/页面标题-1830/index.md
  • 图片存放在同一目录的 images/ 下，Markdown 用相对路径引用。
  • Markdown 头部包含标题、来源链接、站点、作者、保存时间等字段。
  • 图片下载失败时自动保留原始链接，不会中断保存。
  • 每次保存只生成一个 Git 提交（图片和 Markdown 一起提交）。
  • 仓库为空时，第一次保存会自动创建首个提交。

安全说明

Token 仅保存在本机的 chrome.storage.local，不会同步到其他设备，也不会发送给除 api.github.com 以外的任何服务器。请勿把 Token 写进代码或分享给他人； 若怀疑泄露，请立即到 GitHub 撤销并重新生成。

保存的内容会进入你指定的仓库，若仓库是公开的，请注意页面中是否含敏感信息。
